# Civitas

Civitas ist ein Open-Source-Spielprojekt, das Wirtschafts- und Transportaufbau mit einer begehbaren 3D-Welt verbindet. Im Zentrum steht der Aufbau von Industrie, Produktion und Vertriebsnetzen auf festen Karten. Ergänzt wird das später durch Farming und weitere Tätigkeiten aus der First-Person-Perspektive.

## Status

Frühe Prototyp-Phase (Pre-Alpha). Aktuelles Ziel ist eine kleine spielbare Demo mit Welt, Charakter und Grundsteuerung.

## Technik

Godot 4, GDScript, JSON für Spiel- und Konfigurationsdaten.

## Struktur

docs - Dokumentation und Entscheidungen
game - Godot-Projekt
mods - Platzhalter für spätere Mods
tools - Hilfsskripte

## Einstieg

Godot 4 installieren und im Project Manager über Import die Datei game/project.godot öffnen. Details stehen in docs/project_definition_v0.1.md.

## Lizenz

Noch nicht final festgelegt. Open Source ist das Ziel, die konkrete Lizenz folgt später.
